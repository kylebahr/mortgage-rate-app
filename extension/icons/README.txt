Add PNG icons to this folder:
- icon16.png (16x16 pixels)
- icon48.png (48x48 pixels)
- icon128.png (128x128 pixels)

You can use any square images. The extension will still work without them,
but will show a default puzzle piece icon.

Quick option: Download any free icon from https://icons8.com or use a screenshot tool to create simple colored squares.
